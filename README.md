# 📌 About Project

ELEVELT KNOWLEDGE Backend is a modern backend application developed using **Node.js**, **Express.js**, and **MongoDB**.

This backend provides secure REST APIs for managing users, authentication, and application resources efficiently.

---

# ✨ Features

✅ User Authentication  
✅ JWT Authorization  
✅ Secure Password Hashing  
✅ RESTful APIs  
✅ MongoDB Database Integration  
✅ Scalable Backend Structure  
✅ Error Handling Middleware  
✅ Environment Variable Configuration
